# Monthly Expense

An installable iPhone ledger for income, expenses and the independence factor (income ÷ expenses), month by month.

**Open it:** https://cx33032.github.io/monthly-expense/ in Safari, then Share → Add to Home Screen.

- Entries are stored on the device only, in the app's own storage. Nothing is sent to a server.
- Works offline after the first visit.
- **Move data between devices** (Entries tab) copies or merges a ledger with the Claude artifact version, entry by entry: the newer edit wins and deletions carry over.

This repository holds the built app only. It is generated by `build.mjs` in the source project; edit there and rebuild rather than editing these files.
